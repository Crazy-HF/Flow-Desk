## 4. 已知偏差（待确认）

1. **主色保留 `#2563eb`**：参考图用 Element Plus 默认蓝 `#409eff`。本轮按“保留 FlowDesk 品牌”的硬约束没有改品牌色；若要完全贴近参考图，只需改 `styles/element/var-override.scss` 一处。
2. **行内操作按钮仍是圆形**：参考图是圆角方形。`frontend/AGENTS.md` 第 15 条与 `PAGE-TEMPLATE.md` 明确要求 `plain + circle`，本轮未在样板阶段单方面改规范；确认后可一并调整并同步文档。
3. **顶栏没有设置/语言/暗色/全局搜索**：这些能力 FlowDesk 没有，禁用搜索位保持明确禁用，不伪装成可用输入框。
4. **表格列少于参考图**：没有部门、手机号、创建时间等 FlowDesk 不存在的字段；用户列表保留登录名、显示名称、角色、状态、操作。
5. **标签带是自建的最小实现**：不做动态菜单、不做页面缓存、不做布局设置；刷新/深链重置为「首页 + 当前页」，403/登录不进入标签带，登出清空。

## 5. 两个授权抽屉：可用性与风险

### 行为

- 从用户行「分配角色」、角色行「分配权限」打开右侧抽屉；进入时按对象 id 重新取详情与授权关系，不信任行上的旧快照。
- 语义与原授权页一致：**逐条撤销 + 按批授予**，不是整体替换；工具栏的「调整角色」仍是带交接编排的整体替换入口。
- 抽屉里保留「打开完整授权页」链接，原 `/admin/user-roles?userId=`、`/admin/role-permissions?roleId=` 深链继续可用。
- 保存/撤销/清空后只刷新关联数据与当前列表（保留筛选与页码）；关闭后焦点回到触发行（实测 `focusAria=分配角色`）。
- 保护规则原样生效：`SYSTEM_ADMIN` 不能清空；`SYSTEM_ADMIN × RBAC_MANAGE` 不可撤销；移除 IT 支持角色遇到在办工单时，后端 `409` 文案在抽屉内展示。

### 风险

| 风险 | 说明 | 处理 |
| --- | --- | --- |
| 两套授权模型并存 | 抽屉是增量授予；工具栏「调整角色」是整体替换 + 交接 | 抽屉标题写「分配角色」，工具栏保留「调整角色」；确认后可决定是否合并入口 |
| IT 角色移除的交接引导 | 抽屉只能展示 409 原因，完整交接仍在用户管理的替换弹窗 | 抽屉内常驻提示“若名下有在办工单需先交接”；深链按钮可回到用户管理 |
| 旧页面仍在 | 两套界面同时存在，存在双维护成本 | 按指令在用户确认前不删除；确认后再决定是否下线 |
| 抽屉内长列表 | 权限列表 14 项、角色列表 3 项，当前可滚动 | `max-height: 18rem` + 内部滚动；底部操作固定 |
